# v0.12.9 GPU Crash Diagnostics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a testable APK that preserves actionable ARM64/Vulkan crash evidence without speculative GPU fixes.

**Architecture:** A pure-Java bounded log store and crash-summary parser integrate into the existing `GameBootProbe`. `MainActivity` exports the preserved log using Android's document picker. CI runs pure-Java and runtime verifier tests before Gradle.

**Tech Stack:** Java 17, Android API 31+, bash/Python CI, GitHub Actions, bundled ARM64 shadPS4/Vortek/Turnip.

**Spec:** `docs/superpowers/specs/2026-11-05-v0129-diagnostics-design.md`

## Global Constraints

- Keep package `dev.rb4dx.standalone.linuxvk.turnip` with existing signing key and increment version to `0.12.9`.
- Keep the pinned native ARM64 runtime, Vortek and Turnip dependencies unchanged.
- Keep the 18-second vanilla game startup probe and preserve user data.

## Review Focus

- Truncation of oversized UTF-8 data: report exact truncation, retain bounded bytes, avoid OOM.
- Export errors or cancellation: no deletion of the original retained log.
- Missing or malformed crash register fields: no fabricated module address.
- Native crash before the normal game events: preserve log and summarize failure.
- Android upgrade install: same signing identity and increased version code.
